# BEYOND THE FRAME — Personal Portfolio
### Devarakonda Rakesh
> *"A mind in motion. A future in creation."*

An award-grade, Apple-inspired personal portfolio designed and engineered for **Devarakonda Rakesh** — Computer Science student, technology enthusiast, and creative developer.

---

## ✦ Key Highlights

- **Cinematic Opening Sequence:** Minimalist wireframe *DR* monogram animation, typographic reveals, progress indicator, and skip options.
- **Kinetic 3D WebGL Hero:** Interactive architectural wireframe (icosahedron + platinum core + cosmic particles) responsive to mouse inertia, with a self-contained 2D Canvas fallback.
- **Editorial Spatial Design:** Built with pure HTML5 semantic elements, fluid CSS Grid / Flexbox layouts, Syne display typography, and restrained electric-blue / metallic silver accents.
- **Authentic Growth Timeline:** Interactive chronicle tracking real Computer Science academic foundations, programming milestones, and future horizons.
- **Technical Capabilities Inspector:** Deep-dive modal inspector for HTML5, CSS3, JavaScript, Python, C, and future roadmaps.
- **Selected Works Showcase:** Curated project presentations with specification sheets and architecture breakdowns.
- **Native Web Audio Synthesizer:** Atmospheric ambient soundscape synthesized entirely in the browser using the Web Audio API (zero external audio files).
- **Accessible & Responsive:** Full support for `prefers-reduced-motion`, WCAG 2.1 AA keyboard navigation, focus management, and mobile drawer.

---

## 🛠 Tech Stack

- **Markup:** Semantic HTML5, SVG Icons, Open Graph meta architecture
- **Styling:** CSS3, Custom Properties, Backdrop Filter, Fluid Typography (`clamp()`)
- **Logic & Interactions:** Vanilla JavaScript (ESNext), IntersectionObserver
- **Graphics:** WebGL / Three.js with HTML5 Canvas 2D fallback
- **Audio:** Web Audio API (Oscillators, BiquadFilter, GainNode)

---

## 🚀 Running Locally

No heavy node dependencies required. Simply open `index.html` in any modern browser, or run a local static server:

```bash
# Using Python 3
python3 -m http.server 8000
```
Then navigate to `http://localhost:8000`.
